## abertura

- `sb_so_que_mas`: abre com Só que / Mas / Porém
- `sb_e`: abre com 'E'
- `sb_isso_porque`: abre com Isso porque / Isso acontece porque / Porque
- `sb_isso`: abre com Isso / Isso é / Isso significa
- `sb_essa_e`: abre com Essa é a / Esse é o (apresenta o personagem)
- `sb_nome_dele`: abre com O nome dele/dela é / Ele se chama
- `sb_to_falando`: abre com Eu tô falando / Estou falando / Tô falando
- `sb_tempo_atras`: abre voltando no tempo (Tudo começou / Em 19xx / Nos anos / Há X anos / Quando)
- `sb_parece`: abre com Parece / Pode parecer
- `sb_para_entender`: abre com Para entender / Vamos entender / Deixa eu te explicar / Eu explico
- `sb_e_o_mais`: abre com E o mais / E o pior / E o melhor / O mais
- `sb_voce`: abre com Você / Se você
- `sb_artigo`: abre com A/O/Os/As
- `sb_demonst`: abre com Esse/Essa (sem 'é')
- `sb_ele_ela`: abre com Ele/Ela/Eles
- `sb_numero`: abre com número
- `sb_nos_eua`: abre com Nos/Na/No + lugar

## funcao

- `sf_numero`: eleva a aposta com número (algarismo)
- `sf_dinheiro`: traz dinheiro (R$, milhões, bilhões, %)
- `sf_nome`: dá nome ao personagem (nome próprio de pessoa/empresa)
- `sf_chama`: usa 'se chama' / 'o nome' / 'conhecido como'
- `sf_data`: volta no tempo com ano (19xx/20xx) ou 'anos 80'
- `sf_contradiz`: contradiz (só que, mas, porém, na verdade, não é)
- `sf_porque`: explica o porquê (porque, isso porque, o motivo)
- `sf_voce`: puxa para o espectador (você, seu, te)
- `sf_maior`: superlativo (maior, primeiro, único, do mundo)
- `sf_nunca`: nunca / ninguém
- `sf_eles`: eles/elas (sujeito coletivo)
- `sf_brasil`: Brasil ou região BR
- `sf_interior`: interior / cidade pequena
- `sf_historia`: palavra 'história' / 'fundada' (biografia de empresa)
- `sf_apenas`: apenas / só (minimiza)
- `sf_mundo`: o mundo inteiro / o país inteiro
